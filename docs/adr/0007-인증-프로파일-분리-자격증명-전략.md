# 0007. 인증 프로파일(MVP/Production) 분리 + 단계적 자격증명 전략

- 상태: 승인
- 날짜: 2026-06-11

## 맥락

이 템플릿은 ID/PW 로그인 기반의 풀 인증(bcrypt·JWT 쿠키·deny-by-default RBAC)과 프로덕션급 보안
자동화(SAST·SBOM·위협 모델)를 갖춘다. 첫 실사용처인 **검증용 MVP**(아이 드로잉·음성 회고 → 부모
리포트; 한 달 반·500만원)는 범위가 다르다 — 일반 회원가입·계정 시스템이 빠지고, 인증은 **외부 본인
인증(PASS)** 으로 들어온다: _신청 폼 → 링크 → PASS 본인인증 → 만료(expired)까지 세션 → 만료 시 재인증._

PRD 표면("로그인·회원가입 제외", "로그인 없는 링크")만 보면 **인증을 통째로 제거**하는 것으로 읽히지만,
이는 *ID/PW 로그인이 없다*는 뜻이지 *인증이 없다*가 아니다. PASS 본인인증 후 만료까지 유지되는 세션은
템플릿의 JWT 발급 + 만료 + `JwtAuthGuard` 골격과 **같은 패턴**이다. 즉 달라지는 것은 **"누구인지
증명하는 방법(자격증명 발급원)"** 하나뿐이고, **"증명된 사람을 보호 리소스에 잇는 골격"** 은 동일하다.
또한 MVP가 다루는 데이터는 아동의 그림·음성·행동(민감 개인정보, 변호사 재자문 진행 중)이라 데이터
보호 하네스를 약화할 수 없다.

## 결정

인증을 두 책임으로 분리하고, 차이를 **프로파일**로 관리한다.

1. **자격증명 전략(교체) ↔ 공통 세션 골격(불변).**
   - 전략 = _누구인지 증명_ (ID/PW·외부 본인인증(PASS)·SSO). passport 전략 슬롯으로 갈아끼운다.
   - 골격 = JWT 발급·만료(`JWT_EXPIRES_IN`)·`JwtAuthGuard`(deny-by-default)·`RolesGuard`·본인 리소스
     인가. **프로파일과 무관하게 공통 베이스로 유지**한다.

2. **단계적 자격증명 전략.** MVP 프로파일은 외부 본인인증 전략만 활성화한다. 현재 구현된 **ID/PW
   로그인은 삭제하지 않고 비활성 보존**(라우트 미등록/플래그 off·시드 비밀번호 더미)하며, 정식
   단계에서 Local·SSO 전략으로 다시 켠다. → _프로파일 전환으로 제거되는 코드는 없다._

3. **프로파일 차이는 부수 영역에만.** 인증/인가 골격은 두 프로파일 공통이고, 차이는 보안 자동화·운영
   강화에 둔다. MVP 프로파일에서 보류 가능: SAST(Semgrep)·SBOM·위협 모델 풀버전·refresh 토큰
   회전([ADR 0006](0006-refresh-토큰-회전-보류.md))·review-gate·e2e·RBAC 세분화. 체크리스트
   ([secure-harness-nestjs.md](../secure-harness-nestjs.md)) 기준 §0·§8 의 🟡/🟢 다수와 §2 일부가 여기 해당.

4. **데이터 보호 하네스는 프로파일 무관 공통.** 입력 검증·`ClassSerializerInterceptor`+`@Exclude()`·
   helmet/CORS/throttle·gitleaks·`pnpm audit`·구조화 로깅은 MVP에서도 유지한다(아동 민감데이터).

## 결과

- 트레이드오프: 프로파일 개념을 코드·문서에 유지하는 비용이 든다. 자격증명 전략을 슬롯 구조로 정리하면
  현재 단일 Local 전략 대비 추상화가 한 겹 는다(단, passport 가 본래 이 구조를 전제).
- 갭(별도 구현): 외부 본인인증(PASS) 어댑터(시작 URL → 콜백 검증 → 세션 발급), 신청 폼 접수 + 만료
  링크 토큰, 부모↔아이 매핑 기반 본인 인가(IDOR/BOLA)는 템플릿에 없어 신규 작업이다.
- 미결: PASS **expired(세션 만료) 정의 미정**, 음성 수집 동의 변호사 재자문 진행 중 — 세션 만료
  정책·데이터 보존 수위가 확정되면 골격 설정(만료)·하네스 수위를 재검토한다.
- 재검토 트리거: ID/PW 또는 SSO 로그인 정식 도입, PASS expired 확정, 음성 재자문 결과, MVP→정식 전환.
- 추적: 로드맵은 `README.md` / `CLAUDE.md`. 프로파일별 하네스 보류 항목은 체크리스트 헤더 주의문 참고.
