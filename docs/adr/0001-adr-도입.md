# 0001. ADR 도입

- 상태: 승인
- 날짜: 2026-06-11

## 맥락

이 템플릿에는 코드만 봐서는 이유를 알 수 없는 결정이 늘고 있다(린트 룰 개별 채택,
testcontainers 미도입, OpenAPI 생성 방식 등). 근거가 기록되지 않으면 후속 작업자(사람·에이전트)가
같은 검토를 반복하거나, "강화"하려다 의도적 선택을 깨뜨린다. 실제로 `CLAUDE.md` 에
"의도적으로 채택하지 않은 것" 절을 두게 된 배경이기도 하다.

## 결정

`docs/adr/` 에 MADR-lite 형식([template.md](template.md))으로 결정을 기록한다.
매 세션 필요한 가드레일 규칙은 `CLAUDE.md` 가 정본으로 남고, ADR 은 근거·역사를 보관한다
(중복이 아닌 참조 관계).

## 결과

- 트레이드오프: 결정마다 문서화 비용이 든다 — 비자명한 결정에만 작성한다.
- 재검토 트리거: 없음(메타 결정).
